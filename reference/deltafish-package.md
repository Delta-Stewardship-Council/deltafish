# deltafish: Accesses an Integrated Fish Count and Length Dataset from the San Francisco Delta

This package enables streamlined access to a large (45 million
observation) integrated fish dataset from the San Fransisco Delta. The
package downloads published data and stores it in parquet files as an
\`arrow\` dataset in a local cache. Helper functions enable efficient
querying of this large dataset.
